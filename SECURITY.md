# Security Policy

## Supported versions

Security fixes land on the latest `main` branch and on the hosted service
(including the MCP server at `https://tg-analytics.leorigna.com/mcp`).
Older commits and self-hosted installs that are not updated to the latest
`main` do not receive backported fixes.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- Email: `tgram@leorigna.com`
- Or use GitHub private vulnerability reporting:
  <https://github.com/tgram-analytics/server/security/advisories/new>

Please include the affected component (ingestion API, Telegram bot, MCP
server, OAuth flow), steps to reproduce, and the impact you observed.

## What to expect

- We acknowledge your report within 72 hours.
- We fix critical issues as a priority and keep you updated on progress.
- We credit reporters in the fix notes unless you ask us not to.

There is no bug bounty program.
